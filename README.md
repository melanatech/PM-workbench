# PM Workbench

A product management workspace for productivity initiatives.

**Start the course (GitHub Pages):** https://melanatech.github.io/PM-workbench/

## What’s in this repo

- `docs/` — Published interactive course, including a seeded workspace where you can practice the workflows.
- `pm-workbench/` — Companion Claude Code kit (commands, agents, docs, scripts) for use in your own workspace. This folder is in the repo but is not the Pages site.

Actions inside the browser course are **simulations**, not live Claude Code runs or integrations with Jira, Slack, or other services. Running the separate kit locally requires your own setup and any applicable access; practicing in the course does not change external systems.

The original zip is kept locally and is not committed.
