# Job card

Copy to `state/job-card.md` before a multi-draft dispatch. `enforce: on` blocks a later file whose path matches none of `streams`. Add a stream only when the PM expands the job. Do not invent `due`.

enforce: on
job: One sentence finish line
audience: who will read the result
due: YYYY-MM-DD
stop: Do not start a workstream that is not listed
streams: roadmap, release notes
