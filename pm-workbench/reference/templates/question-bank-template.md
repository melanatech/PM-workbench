# Question bank

Keep earlier questions. Add four lenses. Tag every new question with: lens, job, candidate source, atlas status, next step (probe, pull, or companion prompt), and whether it is a net-new feature with no analog.

Status values match the source atlas: accepted, candidate, found-no-join, not-found-after-probe, blocked-with-reason.

The full population is the base. A named subgroup is a cut, never the only population.

## Ramp readout

Return rate by week. Funnel from arrival to the action that finishes the job. Distributions per person and per session (median and upper percentiles). Time to first value. Repeat use. Switching between an old path and a new path. Errors per session. Support contacts before and after. Device split. Subgroup cut.

## Discovery

Unmet jobs in support notes. Searches and dead ends in session replay. Exports that suggest an off-platform tool. Shared access with a partner. Differences by industry or size. Last behavior of people who left. Gaps already named in an existing product-jobs table.

## Monitoring

Health and guardrails (error rate, latency, support volume, export failure). Exposure balance. Novelty decay. Holdout comparison through the experiment platform. One leading indicator per release type.

## Outcome alignment

One question per company objective, and one per strategy objective. Do not add a metric that only describes one surface unless it ladders to a company objective.
