# reference/user-research/

Durable, indexed summaries of research documents — one file per study/report, created the first time `internal-docs-reader` or `/process-inbox` processes a raw document about it, then checked (not re-read from scratch) every time after.

Suggested filename: `[date]-[topic].md`, containing: source document name/location, date, who conducted it, key findings (with page/slide references if useful), and a link back to the original file in `archive/` if it started as a raw drop.

This is what makes "have we researched this before" a fast check instead of a re-read of every past PDF every time.
